# World's Best Engineer (Tiny Engineer)

A 2D puzzle-platformer made in Unity during the **BUG Fall GameJam** at Bahçeşehir University.

> Look! It's a tiny engineer!

**Play it in the browser:** [denizhanemrecan.itch.io](https://denizhanemrecan.itch.io)

## What's inside

- `v2/` — the Unity project (C#)
- Player movement and physics-driven controls (`PlayerController`, `PlayerManager`)
- Level mechanics: moving and dropping platforms, fans, lasers, touch-triggered movers
- Scene flow and game state handling

## Notes

Built end to end within the jam timeframe, so the code favors speed over polish.
